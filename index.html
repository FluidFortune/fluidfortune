[ ABOUT FLUID FORTUNE ]

Fluid Fortune is an independent forge dedicated to building mindful, useful tech. We understand the importance of large systems while also seeing their inner ironies. We operate under a core philosophy: the internet should be a resource, not a dependency, and one should never take it too seriously.

We build tools for the era of private intelligence. You connect to the network to download the payload, but if you choose, the compute itself can stay entirely on your machine. Living by the subscription model should be a choice, not a requirement.

▌ FLAGSHIP

PISCES MOON

v1.2.0 "MULTI-DEVICE" ● NOW PUBLIC

Two inventions that didn't exist before this project. The Ghost Engine — a persistent Core 0 process that wardrives, scans BLE, and logs GPS continuously, always, regardless of what the operator is doing. The device is always collecting. The operator never has to think about it. The SPI Bus Treaty — the first named architectural standard for shared-bus arbitration on the ESP32-S3, the reason the Ghost Engine never stops. One platform. Three Tier 1 devices validated in v1.2.0 — T-Deck Plus (49 apps), T-LoRa Pager (52 apps), and Cardputer ADV (47 apps) — spanning the entire memory tier of the ESP32-S3 chip class from 8 MB PSRAM down to 320 KB internal SRAM with no PSRAM at all. Plus Tier 2 deployment to Pisces Moon Linux on obsolete x86/ARM (77 apps, Debian 13), Android APK, and the Luckfox Pico 86 Panel. Plus a complete browser-based developer ecosystem: Lety — the in-browser IDE with live preview, cloud build, and Web Serial flash to your T-Deck. Pisces Bridge — firmware that turns any $10 ESP32 dev board into a sensor that streams WiFi, BLE, LoRa, and GPS detections to any host. Ghost Partition security, local AI inference, LoRa mesh radio, GPS, and ELF module runtime — on hardware costing $45 to $350. Sovereign by design: fully functional offline, optionally networked as an edge node. Eleven engineering problems documented and solved — none of which had documented prior solutions on this hardware platform. As of May 2026, the operating system runs concurrent four-radio operation on hardware the industry treats as incapable of running an OS at all. The operator chooses.

TROJAN HORSE

v0.1.0-alpha

A native application wrapper that turns any HTML/JS app into a real desktop application — without Electron's 200MB runtime, without Node.js, without an App Store. ~500 lines of native code per platform. Ships on macOS, Linux, Windows, Android, and iOS. The window.spadra.* bridge gives web apps direct access to the filesystem, serial ports, OS notifications, and hardware — including the T-Deck Plus running Pisces Moon OS. The deployment layer for the entire Fluid Fortune ecosystem.

VIEW ON GITHUB

THE LIGHTHOUSE

v0.1.0-alpha

A signal between your device and your AI. The Lighthouse is a lightweight Python server that sits between any HTTP client and your existing Claude.ai or Gemini browser session — no API key, no extra cost, no per-token billing. It types your message, waits for the response, and returns it as JSON. The AI you already pay for, with your existing Projects and memory intact, accessible from any device that can make an HTTP POST. A $60 ESP32 device. A Raspberry Pi. curl. Anything.

A standard API call returns "Hello! How can I help you today?" The Lighthouse returns a continuation of an existing relationship.
